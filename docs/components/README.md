# Пользовательские руководства компонентов

Файл `<slug>.yaml` дополняет технический YAML MetaKit понятным инженерным
описанием. Технические сведения не дублируются: значения по умолчанию, список
параметров, Data, Instances и ST всегда читаются из самого компонента.

Руководство содержит:

- назначение и границы применения;
- схему работы простыми словами;
- быстрый старт;
- проверяемые примеры настройки;
- описание каждого параметра;
- состав HMI по умолчанию и доступные дополнительные сигналы;
- аварии, предупреждения и частые ошибки.

`tools/validate_metakit.py` требует, чтобы для каждого параметра компонента было
описание, а примеры не ссылались на несуществующие параметры. Это не позволяет
документации незаметно устареть после изменения MetaKit.
