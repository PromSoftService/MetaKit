# Руководства компонентов

Каждый файл `<slug>.yaml` — самостоятельный источник человеко-ориентированной
документации. Он не формируется из технического компонента и не обязан повторять
внутреннее устройство MetaGen.

Руководство содержит:

- назначение и границы применения;
- наглядную схему прохождения сигналов;
- пример заполнения параметров в виде таблицы MetaPlatform;
- простое описание каждого параметра;
- настройки со значениями по умолчанию;
- теги HMI, аварии, предупреждения и тренды;
- аварии, предупреждения и частые ошибки.

Поле `source` связывает руководство с файлом в `yaml/`, чтобы пользователь мог
скачать компонент со страницы, а сборка — добавить его в общий архив. Проверка
контролирует структуру самих руководств и наличие связанных файлов, но не
анализирует содержимое MetaGen YAML.
