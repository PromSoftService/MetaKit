# Общие настройки однотипных объектов

Псевдонимы конфигурации позволяют хранить общие настройки нескольких однотипных исполнительных механизмов или регуляторов в одном наборе тегов `Conf`.

Например, если два двигателя имеют одинаковый `EngConf = PUMP`, оба используют теги вида:

```text
Conf.PUMP_Engine_diStateControlTime
Conf.PUMP_Engine_diStateConfirmTime
```

Если `EngConf` пустой, префиксом становится индивидуальный `Id` двигателя.

Общими можно делать только действительно одинаковые настройки. Проект должен проходить проверку на совпадение значений и комментариев для каждого повторяющегося конфигурационного ключа.
