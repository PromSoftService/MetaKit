# Контроль связи WatchDog

WatchDog оформляется отдельным проектным компонентом и не встраивается в `General`, двигатель, клапан или другой технологический Unit.

- `WDMaster` формирует контрольное слово и принимает ответ ведомого устройства.
- `WDSlave` принимает слово ведущего устройства и формирует ответ.
- `WDSimple` контролирует изменение одного входного слова без парной логики Master/Slave.

Для формирования предупреждения об отсутствии связи в строке `out_bConn` следует установить `Wrn = false`. Сам сигнал ошибки связи не должен автоматически вмешиваться в технологический алгоритм: необходимую реакцию определяет проектировщик конкретной системы.
