# MetaKit

MetaKit — библиотека компонентов MetaGen для построения прикладных PLC-проектов на основе функциональных блоков MetaLib.

Репозиторий содержит:

- `yaml/LibTempls` — отдельные шаблоны функциональных блоков;
- `yaml/UnitsTmpls` — готовые контуры управления;
- `yaml/SysTmpls` — компоненты уровня проекта;
- `docs/components` — написанные вручную руководства по каждому компоненту;
- `docs` — общие статьи и оформление документации;
- `tools` — сборка и проверка статического сайта.

Документация ориентирована на инженера: объясняет назначение компонента,
порядок применения, параметры, настройки и данные для HMI. Сборщик не извлекает
описания из технического YAML и не подменяет инженерную документацию автогенерацией.

## Локальная сборка документации

```bash
python -m pip install -r requirements-docs.txt
make check
make docs
```

Готовая статическая документация создаётся в `dist/docs`. Каталог рассчитан на
публикацию по адресу `/docs/` и включает страницы компонентов, исходные YAML для
индивидуальной загрузки и полный архив `MetaKit_{timestamp}.zip`.

Для локального просмотра:

```bash
python -m http.server 8000 --directory dist
```

После этого документация доступна по адресу `http://localhost:8000/docs/`.

Подробнее: [развёртывание документации](docs/deployment.md).
