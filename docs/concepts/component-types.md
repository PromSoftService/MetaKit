# Типы компонентов

## Lib-компоненты

`LibTempls` — индивидуальные шаблоны функциональных блоков MetaLib. Они используются, когда инженер собирает собственный контур управления из нескольких блоков. Идентификаторы и параметры Lib-компонентов имеют собственные префиксы, чтобы разные типы блоков можно было безопасно объединять в одном компоненте.

Импорт двух одинаковых Lib-компонентов в один пользовательский компонент возможен, но инженер обязан развести совпадающие имена параметров.

## Unit-компоненты

`UnitsTmpls` — заранее сформированные контуры управления. Они объединяют интерфейс `CCascadeUnit`, исполнительный механизм, регулятор и обработку аварий или предупреждений. Внутри Unit применяется единый `Id` и общий человеческий `Comment`.

Unit подходит, когда его готовая структура соответствует технологической задаче. Если требуется нестандартное сочетание блоков, правильнее собрать собственный компонент из Lib-шаблонов.

## Sys-компоненты

`SysTmpls` — инфраструктура уровня проекта: контроллер шкафа, общие аварии и предупреждения, контроль границ датчиков. Такие компоненты не следует автоматически встраивать в каждый Unit.
